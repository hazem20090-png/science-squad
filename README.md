# Science Squad

Static chemistry practice site with 150 original bilingual questions, slides, answer validation, local progress, retries, video links, dark mode, and reduced-motion support.

## Publish with GitHub Pages

1. Create the repository `hazem20090-png/science-squad`.
2. Push this folder's `main` branch to it.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. The live address will be `https://hazem20090-png.github.io/science-squad/`.
